# 上传到私有GitHub仓库

1. 解压发布ZIP，选择 extractive-distillation-agent 文件夹作为仓库根目录。
2. 登录GitHub，新建同名仓库，选择 Private。不要上传整个原始677 MB资料包。
3. 使用GitHub Desktop添加这个本地文件夹；如提示尚非Git仓库，选择在此创建仓库。
4. 查看 Changes，确认没有真实密钥、原论文和无关文件，再提交 Initial V4 manuscript snapshot。
5. Publish repository 时保持 Keep this code private，上传后检查README和cases目录。
6. 当前属于私有整理版；先核对运行环境、原始模型依赖和GBL费用修正，再发布论文版本。公开前与共同作者确认许可证。

若网页上传，上传解压后的文件及文件夹，而不是仅上传ZIP。大型原始计算资料保留在独立归档中。
